# 📚 Flashcards 功能使用指南

## 快速开始

### 1. 准备工作

确保已配置 DeepSeek API Key：

```bash
# 在 .env.local 文件中添加
DEEPSEEK_API_KEY=your_deepseek_api_key
```

### 2. 上传文档

1. 访问首页
2. 上传文档（支持 PDF、TXT、DOCX 等格式）
3. 等待文档转换完成

### 3. 进入 Workspace

1. 点击上传的文档
2. 进入 Workspace 编辑页面

### 4. 切换到 Flashcards 模式

1. 在左侧 Sidebar 中找到 "Quick Tools" 区域
2. 点击 "Flashcards" 按钮
3. 页面切换为左右布局：
   - 左侧：闪卡区域
   - 右侧：聊天界面

### 5. 生成闪卡

1. 点击"生成闪卡"按钮
2. AI 将分析文档内容，生成 12 个问答卡片
3. 等待几秒钟，闪卡生成完成

### 6. 学习闪卡

#### 查看卡片
- **正面**：显示问题（蓝色主题）
- **背面**：显示答案和解释（绿色主题）
- **翻转**：点击卡片即可翻转

#### 导航卡片
- **按钮导航**：
  - 点击"上一张"按钮查看上一张卡片
  - 点击"下一张"按钮查看下一张卡片
  
- **键盘导航**：
  - 按 `←` 键查看上一张
  - 按 `→` 键查看下一张

#### 查看进度
- 卡片上方显示进度指示器，格式为 "1/12"
- 表示当前是第 1 张，共 12 张卡片

### 7. 配合聊天学习

右侧的聊天界面可以帮助你深入理解卡片内容：

1. 在聊天框中输入问题
2. AI 基于文档内容回答
3. 例如：
   - "请详细解释第 3 张卡片的内容"
   - "这个概念有什么实际应用？"
   - "能举个例子吗？"

### 8. 重新生成闪卡

如果对生成的闪卡不满意：

1. 滚动到页面底部
2. 点击"重新生成闪卡"按钮
3. AI 将重新分析文档，生成新的 12 张卡片

## 最佳实践

### 1. 学习策略
- **首次学习**：按顺序查看所有卡片，理解每个概念
- **重点复习**：对不熟悉的内容，使用聊天功能深入了解
- **定期复习**：定期重新查看闪卡，巩固记忆

### 2. 配合聊天
- 遇到不理解的概念，立即在聊天中询问
- 要求 AI 提供更多例子或应用场景
- 让 AI 用不同的方式解释同一个概念

### 3. 文档准备
- 上传内容丰富、结构清晰的文档
- 文档应包含明确的概念和定义
- 避免上传纯数据或表格类文档

## 常见问题

### Q: 为什么生成的闪卡数量少于 12 个？
A: 可能是文档内容较少，AI 无法提取足够的概念。建议上传内容更丰富的文档。

### Q: 闪卡内容不准确怎么办？
A: 点击"重新生成闪卡"按钮，AI 会重新分析文档。如果问题持续，可能是文档内容不够清晰。

### Q: 可以编辑闪卡内容吗？
A: 当前版本不支持编辑，此功能在后续版本中会添加。

### Q: 闪卡会保存吗？
A: 当前版本闪卡仅在会话中保存，刷新页面后需要重新生成。后续版本会添加持久化存储。

### Q: 支持导出闪卡吗？
A: 当前版本不支持导出，此功能在后续版本中会添加。

## 技术支持

如遇到问题，请检查：

1. **API Key 配置**：确保 DEEPSEEK_API_KEY 已正确配置
2. **网络连接**：确保可以访问 DeepSeek API
3. **文档内容**：确保上传的文档有足够的文本内容
4. **浏览器控制台**：查看是否有错误信息
