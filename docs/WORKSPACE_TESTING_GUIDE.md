# 🧪 Workspace 聊天功能测试指南

## 快速测试步骤

### 1. 启动开发服务器

```bash
pnpm dev
```

等待服务器启动，应该看到：
```
✓ Ready in 3.3s
Local: http://localhost:3000
```

### 2. 准备测试文档

1. 访问 http://localhost:3000/en/convert
2. 上传一个文档文件（Word/PDF/TXT）
3. 等待转换完成
4. 点击 "Advanced Edit" 按钮

### 3. 测试 Document 模式（默认）

**预期布局**:
```
┌─────────────────────────────────────────────────┐
│                   Toolbar                       │
├──────┬──────────────────┬──────────────────────┤
│      │                  │                      │
│      │   AI 学习笔记     │     聊天界面          │
│ Side │   (左侧 50%)     │    (右侧 50%)        │
│ bar  │                  │                      │
└──────┴──────────────────┴──────────────────────┘
```

**测试项**:
- [ ] 左侧显示 "AI 学习笔记" 标题
- [ ] 左侧自动生成学习笔记（流式显示）
- [ ] 右侧显示 "AI 助手" 聊天界面
- [ ] 右侧显示欢迎消息和提示

### 4. 测试聊天功能

**基础对话**:
1. 在右侧聊天框输入："这个文档讲了什么？"
2. 点击发送按钮（或按 Enter）
3. 观察 AI 回复（应该基于文档内容）

**预期行为**:
- [ ] 用户消息显示在右侧（蓝色背景）
- [ ] AI 回复显示在左侧（灰色背景）
- [ ] AI 回复有打字机效果（流式显示）
- [ ] 消息自动滚动到底部
- [ ] 发送中按钮显示加载图标

**多轮对话**:
1. 继续提问："能详细解释一下吗？"
2. 再问："有什么重点需要记住？"

**预期行为**:
- [ ] AI 能记住上下文
- [ ] 回答连贯且相关
- [ ] 消息历史正确显示

### 5. 测试快捷键

**Enter 发送**:
1. 输入消息
2. 按 Enter 键
3. 消息应该发送

**Shift+Enter 换行**:
1. 输入一些文字
2. 按 Shift+Enter
3. 应该换行而不是发送

### 6. 测试模式切换

**切换到 Chatbot 模式**:
1. 点击左侧 Sidebar 的 "Chatbot" 按钮
2. 观察布局变化

**预期行为**:
- [ ] 聊天界面全屏显示
- [ ] AI 学习笔记隐藏
- [ ] Chatbot 按钮高亮显示
- [ ] 对话历史保留

**切换回 Document 模式**:
1. 点击左侧 Sidebar 的 "Document" 按钮
2. 观察布局变化

**预期行为**:
- [ ] 恢复左右分屏布局
- [ ] AI 学习笔记重新显示
- [ ] Document 按钮高亮显示
- [ ] 对话历史保留

### 7. 测试其他按钮

**Flashcards 按钮**:
1. 点击 "Flashcards" 按钮
2. 应该显示 "功能开发中" 提示

**Quiz 按钮**:
1. 点击 "Quiz" 按钮
2. 应该显示 "功能开发中" 提示

### 8. 测试边界情况

**空消息**:
1. 不输入任何内容
2. 点击发送按钮
3. 应该无法发送（按钮禁用）

**加载中重复发送**:
1. 发送一条消息
2. 在 AI 回复完成前再次点击发送
3. 应该无法发送（按钮禁用）

**长消息**:
1. 输入一段很长的文字（500+ 字）
2. 发送并观察显示效果
3. 应该正确换行和显示

**特殊字符**:
1. 输入包含特殊字符的消息：`<script>alert('test')</script>`
2. 发送并观察
3. 应该正确转义，不执行脚本

### 9. 测试错误处理

**网络错误模拟**:
1. 打开浏览器开发者工具
2. 切换到 Network 标签
3. 设置为 Offline 模式
4. 发送消息
5. 应该显示错误提示

**API 错误**:
1. 临时修改 `.env.local` 中的 `DEEPSEEK_API_KEY` 为无效值
2. 重启服务器
3. 发送消息
4. 应该显示 API 错误提示

## 性能测试

### 流式响应性能

**测试步骤**:
1. 提问："请详细总结这个文档的所有内容"
2. 观察 AI 回复的流式显示
3. 记录响应时间

**预期性能**:
- 首字响应时间：< 2 秒
- 流式显示：流畅无卡顿
- 完整回复时间：< 30 秒（取决于内容长度）

### 内存使用

**测试步骤**:
1. 打开浏览器开发者工具 → Performance Monitor
2. 进行 10 轮对话
3. 观察内存使用情况

**预期行为**:
- 内存增长平稳
- 无明显内存泄漏
- 页面响应流畅

## 常见问题排查

### 问题 1: AI 不回复

**检查项**:
1. 浏览器控制台是否有错误
2. Network 标签是否显示 API 请求失败
3. `.env.local` 中 `DEEPSEEK_API_KEY` 是否配置
4. 服务器是否正常运行

### 问题 2: 流式显示不工作

**检查项**:
1. 浏览器是否支持 ReadableStream
2. 网络连接是否稳定
3. API 响应是否正常

### 问题 3: 布局错乱

**检查项**:
1. 浏览器缓存是否清除
2. CSS 是否正确加载
3. 浏览器窗口大小是否合适

### 问题 4: 对话历史丢失

**说明**:
- 当前版本不持久化对话历史
- 刷新页面会丢失对话
- 这是预期行为，后续版本会改进

### 测试用例示例

// 示例：测试聊天发送功能
test('should send message and receive AI reply', async () => {
  // 1. 输入消息
  await page.fill('[placeholder*="输入消息"]', '你好');
  
  // 2. 点击发送
  await page.click('button[type="submit"]');
  
  // 3. 等待 AI 回复
  await page.waitForSelector('.ai-message');
  
  // 4. 验证消息显示

  expect(messages.length).toBeGreaterThan(1);
});
